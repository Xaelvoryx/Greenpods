ASSIGNMENT-2

1.Understanding of the Dataset

2.Understanding of Model Selection

3.Understanding of Evaluation Metrics
  Clear reasoning behind the metrics you chose (Accuracy, F1-score, Recall, etc.)
  Explanation of how these metrics helped you decide which model performs best
  Prepare a report including all the above, along with one example run demonstrating how your      model works.
